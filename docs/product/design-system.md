# Design system

The admin and user panels use a restrained operations-console language: mineral paper backgrounds, deep ink surfaces, teal action states, rust for destructive/error states, and hairline borders instead of gradients. Aptos/Trebuchet/system UI typography keeps dense operational data readable without importing a remote font.

Both surfaces use a 14px radius for primary shells, 8-11px radii for controls and records, high-contrast focus rings, and responsive single-column fallbacks below 720-860px. The admin panel uses a dark sticky navigation rail on wide screens; the user panel uses a workbench hierarchy that puts URL creation and ownership records ahead of secondary decoration. Dark mode preserves the same semantic color roles rather than inverting status meaning.
